# 3D asset source of truth

This directory contains the stable, canonical paths consumed by the game and
the public collection. Do not rename or move a production GLB without updating
the game, collection manifest, audit data, and build scripts together.

## What belongs here

| Files | Role |
| --- | --- |
| `*.glb` | Canonical, optimized runtime models |
| `*.blend` | Editable Blender projects for models that use Blender sources |
| `residents/` | Resident runtime models and their Blender projects |
| `lost-heritage/` | GLBs generated from `src/lost-heritage/models.js`; these intentionally have no `.blend` files |
| `previews/` | Canonical model previews used by the collection |
| `vendor/` | Vendor provenance and integration information |

Most Blender-backed models use matching names, such as `bench-v2.blend` and
`bench-v2.glb`. The deliberate exceptions are:

- `hdb-call-kit.blend` exports `hdb-call-v2.glb`.
- `engineer-v2.glb`, `landed-v2.glb`, `raintree-v2.glb`, and
  `service-van-v2.glb` are generated by
  `scripts/blender/rebuild-hero-components.py`.
- The thirteen `lost-heritage/*.glb` models are generated by
  `scripts/export-lost-heritage-glbs.mjs`.

The collection contains 74 of the 75 canonical GLBs. The additional
`alfa-romeo-giulia-spider-v2.glb` is a game experience asset and is
intentionally outside the collection manifest.

## What does not belong here

- Blender autosaves (`*.blend1`).
- Local conflict copies with names such as `model 2.blend`.
- Build output copied from `dist/` or `showcase/public/models/`.
- The five procedural pre-refinement GLBs from the Singapore asset pipeline.

Run `npm run assets:check` after changing models. Run the game and collection
builds to regenerate their ignored runtime copies.
