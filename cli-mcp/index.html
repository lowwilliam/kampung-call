Part one · get moving

Your first useful CLI session

Work from a real project folder. Keep the task small enough that you can understand and review the result.

  1. 01

    Install

    Put Codex on your machine

    On macOS or Linux, use the standalone installer. Running it again updates Codex.

    curl -fsSL https://chatgpt.com/codex/install.sh | sh
  2. 02

    Open a project

    Start where the code lives

    Move into the repository you want Codex to understand, then launch the interactive terminal UI.

    cd ~/projects/my-app
    codex
  3. 03

    Ask

    Describe an outcome, not keystrokes

    Say what should change, where to look, what must stay true, and how to prove it worked.

    ›

    In the checkout form, fix the empty-state bug. Keep the current visual design, add a regression test, and run the relevant checks.

  4. 04

    Review

    Inspect before you ship

    Watch commands as they run, read the diff, ask follow-up questions, and use /review for a dedicated pass.

    /review

Part two · build the habit

The four-beat CLI loop

Good sessions are conversations with checkpoints—not one giant prompt and a leap of faith.

  1. 1

    Ask

    Set a concrete outcome and useful boundaries.

  2. 2

    Watch

    See what Codex reads, runs, and changes.

  3. 3

    Steer

    Correct assumptions early or add missing context.

  4. 4

    Review

    Check the diff and evidence before committing.

Part three · extend the reach

MCP, without the mystery

MCP stands for Model Context Protocol. An MCP server publishes tools and context in a format Codex understands. Configure a connection once on your Codex host; the CLI, desktop app, and IDE extension can share it.

>_Codexthe agent

Local · STDIO

Started as a process

Codex runs a command on your machine and communicates with that server directly.

npx -y @upstash/context7-mcp

Remote · HTTP

Reached at a URL

Codex connects to a Streamable HTTP endpoint, optionally using a bearer token or OAuth.

https://example.com/mcp

Connect once, reuse it

Add a documentation server

This is setup, not something you paste for every task. Once connected, use the universal starter prompt above and let Codex choose the server when it helps.

about 2 min
  1. 1
    Add it
    codex mcp add context7 -- npx -y @upstash/context7-mcp
  2. 2
    Confirm it
    codex mcp list
  3. 3
    See it in a session
    /mcp

OAuth server? Run codex mcp login <server-name>, then complete sign-in in your browser.

Before you connect everything

Access is a feature. Scope it.

01

Start read-only

Begin with tools that inspect data. Add write actions only when the workflow needs them.

02

Keep secrets out of prompts

Pass tokens through environment variables or the server’s supported authentication flow.

03

Limit the tool set

Enable only the tools the task needs, especially for servers with broad access.

04

Review consequential actions

Keep approval prompts for writes, messages, deployments, and anything hard to undo.
