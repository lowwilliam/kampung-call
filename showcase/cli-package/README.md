# Kampung Assets CLI

Search and inspect the public Kampung 3D Collection from a terminal. The CLI uses the ChatGPT-hosted collection by default.

```bash
kampung-assets list --query heritage
kampung-assets get game:peranakan-house
kampung-assets download game:peranakan-house -o ./peranakan-house.glb
```

Downloads remain unavailable until the catalogue record has a cleared Download Grant.
