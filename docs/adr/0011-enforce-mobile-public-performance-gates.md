# Enforce mobile-public performance gates

The Collection will treat mobile performance and accessibility as release contracts: list cards load no WebGL, a Detail View runs at most one interactive scene and becomes usable within five seconds, and the Memory District streams nearby regions rather than parsing all 13 models at entry. Controlled mobile tests must hold LCP at or below 2.5 seconds, INP at or below 200 milliseconds, CLS at or below 0.1, exploration at or above 30 FPS on the reference mid-range device, and no sustained memory growth; CI must fail on breached package, model, or critical-path budgets. The same release must meet WCAG 2.2 AA and support the current and previous two major versions of Safari, Chrome, Edge, and Firefox, with the complete static experience replacing interactive 3D when WebGL or device capability is insufficient. CI uses recorded mobile throttling, and every public release is also verified on a Pixel 6a-class Android device and an iPhone 12-class iOS device, with actual model and operating-system versions recorded.
