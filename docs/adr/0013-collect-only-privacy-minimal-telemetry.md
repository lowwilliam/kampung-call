# Collect only privacy-minimal catalogue telemetry

The public Collection may collect anonymous aggregate counts for page visits, Detail View opens, grant-authorised downloads, WebGL failures, and performance measurements through a same-origin, cookie-free, rate-limited beacon with a fixed schema and no free-text fields. Request-level telemetry is not persisted; daily aggregates are retained for 13 months. It will not store raw search terms, use advertising cookies, create user profiles, or fingerprint devices; factual corrections use a prefilled email containing the stable Game Asset ID rather than reopening a database-backed public write surface. The production domain and dedicated corrections address remain required release configuration and must not be invented in source.
