# Offer downloads only under asset-specific grants

The Showcase may offer a Game Asset for download only when its Catalogue Manifest record contains completed Rights Clearance and an explicit Download Grant covering creator credit, source, licence, attribution, reuse, and redistribution conditions. The default is blocked. Eligible wholly controlled first-party models use CC BY-NC 4.0; the licence covers only rights the project owns and does not grant rights in excluded buildings, sculptures, source media, trademarks, likenesses, or third-party components. Any asset that cannot be relicensed under those terms remains unavailable for download. Modern landmarks, post-10-April-1987 buildings, religious, university, and airport subjects, trademark-bearing models, recognisable people, and reconstructions with uncleared photographs or plans require documented specialist review or permission before public distribution. The Harbour Statue requires written Singapore Tourism Board clearance for any Merlion-resembling form; without it, that model remains blocked or must be redesigned into a non-recognisable original work. The website, read-only API, CLI, and MCP use the same grant decision. Each download is an asset-specific ZIP containing the published GLB, `LICENSE.txt`, provenance JSON, and a README; the first release has no 68-asset bulk archive. Public display, repository presence, a `free` or `premium` tier label, a source link, or a disclaimer never implies redistribution permission. Licensed threejsassets Scenery Components may be embedded in the game but cannot be offered as standalone downloads under the provider's current terms; a first-party fallback may have different terms and must be credited as the Source Variant actually delivered.
