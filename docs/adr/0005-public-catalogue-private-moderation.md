# Keep the catalogue public and moderation private

The catalogue, Detail Views, reports, and account-free submission flow will be public. Submission Receipts require an unguessable private secret and the admin portal requires a password, while unpublished models, review data, and Quarantine objects remain inaccessible to public queries. The default catalogue opens on the curated `From Kampung Call` collection; `Made in Singapore` ranks administrator-featured work before newly published contributions rather than using popularity metrics.
