# Release through a gated private preview

The new Manifest-driven Collection and Memory District will first run in a private environment, then in a small noindex acceptance preview, and only then replace the public Collection in one release after all 68 assets have Display Clearance. Community data is inventoried before any destructive cleanup, and Community code and write infrastructure are removed only after the replacement is accepted; download controls appear solely for the individually cleared subset. Production remains blocked without a real domain, dedicated corrections email, 68 Display Clearances, per-download grants, STB permission or redesign for the Harbour Statue, professional conclusions for high-risk assets, Community data inventory, and recorded Android and iOS device acceptance.
