# Retire community writes and keep a read-only metadata API

The public release will remove the Community collection, likes, submissions, reports, receipts, moderation portal, D1/R2 workflow, and all upload and recovery commands. Before destructive cleanup, the release process must inventory any existing Community data, retain only the minimum private audit record when legally or operationally required, and delete submitted models, LinkedIn URLs, other personal data, and abandoned production write resources. It will retain read-only metadata, search, and grant-controlled download capabilities for the 68 curated Game Assets across the website, API, CLI, and MCP so institutions and other clients can consume the authoritative catalogue without reopening a public write surface.
